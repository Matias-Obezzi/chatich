Overlays de Eventos

Catálogo interactivo de alertas, metas, encuestas y pantallas, alimentados por los eventos de Twitch, Kick y YouTube.

1. Alertas de evento

Cola real de eventos encadenados. Si llegan varios a la vez (ej. un raid y una suscripción), se encolan y reproducen uno atrás de otro.

Arquitectura Objetivo

Para soportar todos estos widgets sin acoplarlos al MessagesContext actual (que solo entiende de mensajes), se debe normalizar el modelo usando un StreamEvent y un EventBus.

export type StreamEvent = | { type: 'chat.message'; payload: ChatMessage } | { type: 'chat.delete'; payload: { messageId: string } } | { type: 'sub' | 'sub.gift' | 'follow' | 'raid' | 'cheer'; payload: AlertPayload } | { type: 'poll.update'; payload: PollData }; export interface EventsContextType { subscribe: (types: StreamEvent['type'][], callback: (e: StreamEvent) => void) => () => void; emit: (event: StreamEvent) => void; } export interface OverlayDefinition { id: string; name: string; component: React.ComponentType<any>; events: StreamEvent['type'][]; }

Consistente con la fase 1 del roadmap en arquitectura.html. Los componentes en /overlay/[type] solo se suscriben a los eventos que declaran necesitar.
